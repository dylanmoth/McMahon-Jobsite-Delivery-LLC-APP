McMahon Dispatch Fleet Management v0.7.0

1. Close McMahon Dispatch.
2. Back up the existing project folder.
3. Copy the contents of this patch into the project root.
4. Choose Replace files in the destination.
5. Run:
   .\.venv\Scripts\python.exe -m pip install -e ".[dev]"
   .\.venv\Scripts\python.exe -m pytest
   .\.venv\Scripts\python.exe -m mcmahon_dispatch

No Alembic migration is required. The normalized v0.2 schema already includes vehicles, maintenance_records, fuel_entries, registration, insurance, odometer, MPG, and cost-per-mile fields.
