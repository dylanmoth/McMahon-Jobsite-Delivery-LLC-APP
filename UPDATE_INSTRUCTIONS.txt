McMahon Dispatch Quote Builder v0.5.1.1 Resize Hotfix

1. Close McMahon Dispatch.
2. Copy the src folder from this patch into the McMahonDispatch project root.
3. Choose Replace the files in the destination.
4. No migration or dependency installation is required.
5. Run: .\.venv\Scripts\python.exe -m mcmahon_dispatch

Fix: Renames quote dimension widgets from self.width/self.height to self.load_width/self.load_height so they no longer shadow QWidget.width() and QWidget.height().
